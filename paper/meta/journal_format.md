# Journal and preprint format

Primary immediate target: arXiv preprint.

Downstream target: IEEE Access.

- Source format: LaTeX using `IEEEtran` journal mode.
- Layout: two-column, single-spaced journal layout.
- Abstract: one paragraph, no citations, equations, or footnotes.
- References: numbered IEEE style.
- Figures and tables: cited in order, captions self-contained.
- Recommended IEEE Access length: no more than 20 pages.
- arXiv category candidate: `cs.AI`, with `cs.MM` considered as a cross-list.
- Submission files must contain no private dataset files, API secrets, or local absolute paths.
- AI-assisted text must be disclosed if required by the destination policy.
