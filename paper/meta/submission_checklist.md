# Submission checklist

## Technical manuscript

- [x] Complete English manuscript draft.
- [x] Claims separated into primary, diagnostic, and external evidence.
- [x] Quantitative claims linked to tables and experiment run identifiers.
- [x] Limitations state the Ridge-backbone and EmotionTalk contract-level boundaries.
- [ ] Compile LaTeX and resolve layout warnings.
- [ ] Run final reference and numerical consistency audit after compilation.

## Author-provided metadata

- [ ] Replace author, affiliation, and corresponding email placeholders.
- [ ] Add ORCID identifiers if desired.
- [ ] Add actual funding statement.
- [ ] Add public code repository URL and immutable release identifier.
- [ ] Confirm dataset licenses permit the described use.
- [ ] Approve the AI-assistance disclosure.
- [ ] Confirm arXiv category and endorsement status.

## arXiv package

- [ ] Include `main.tex`, `references.bib`, and `figures/amac_overview.tex`.
- [ ] Exclude local experiment outputs, raw datasets, secrets, and absolute paths.
- [ ] Inspect the arXiv-generated PDF before announcing the preprint.
