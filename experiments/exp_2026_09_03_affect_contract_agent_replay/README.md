# Affect Contract Agent Replay

This experiment verifies that the repository's real `affect_contract` Agent tool
reproduces the frozen offline LR commitment trajectories on every CH-SIMS v2 test
clip and all six modality arrival orders.

It measures local decision latency and checks invalid-session, duplicate-modality,
invalid-probability, invalid-modality, forced-finalization, and reset behavior.
Latency is descriptive for this machine and is not claimed as universal.
