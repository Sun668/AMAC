# EmotionTalk Contract-Level External Validation

This experiment evaluates whether the CH-SIMS v2-selected learned risk
contract transfers in direction to a newer public Chinese multimodal emotion
dataset. EmotionTalk provides independent five-rater annotations for text,
audio, video, and full multimodal presentation of the same clips.

The single-modality consensus labels and confidence are treated as frozen
upstream affect-sensor outputs. The separately annotated multimodal consensus
is the target. Therefore this experiment tests the Agent commitment contract,
not raw-media perception, and must not be reported as end-to-end EmotionTalk
classification or as an official benchmark result.
