# PLAN

1. Require a passed independent validator and explicit test authorization from
   `risk_contract_v1`.
2. Freeze the selected condition `H0`, five seeds, seed-specific B2/B4/H0
   parameters, data hash, dependency hashes, runner hash, and validator hash.
3. Run once on all 1,034 CH-SIMS v2 test clips and all six arrival orders.
4. Independently recompute row identities, metrics, paired intervals, official
   anchors, hashes, and claim gates from saved artifacts.
5. Treat a valid weak result as a limitation; never retune after test access.

Primary evidence compares H0 with B4 at matched stage-two service coverage.
B2 is a second deployable baseline; B3 is interpreted together with its
coverage. B0/B1 are endpoint controls and O1 is label-aware diagnostic only.
