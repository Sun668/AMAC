run in `exp_2026_09_03_amac_stronger_backbone`. It tests one frozen primary
claim: H0 reduces incorrect pre-final commitments versus B4 at matched
stage-two coverage when both use a nonlinear, subset-aware fusion backbone.

The test output is immutable and accepted only after independent validation.
